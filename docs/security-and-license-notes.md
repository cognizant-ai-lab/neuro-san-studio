# Security and license notes

- All customers, accounts, devices, sessions, merchants, beneficiaries, locations, transactions, alerts, campaigns, and hidden labels are generated locally with a fixed seed. No Cognizant, bank, or client data is used.
- `.env.example` contains placeholders only. API keys must be supplied through a local `.env` file or process environment and are never logged, persisted in passports, or committed.
- The command center has no production connector or side effect. Human approval moves a synthetic control to `SHADOW`; it cannot activate a real bank rule.
- The application does not claim regulatory approval, production certification, fraud-loss guarantees, or compliance with a specific banking regulation.
- Neuro SAN Studio remains Apache-2.0 licensed under the repository `LICENSE.txt`. New project code is original repository code and follows the repository license. The prototype does not embed AMLSim, Tide, SynthFin-AML, AMLBench, PaySim, or other external dataset/code; public datasets were treated as research inspiration only to avoid unreviewed license and distribution obligations.
- Dataset review: [IBM AMLSim](https://github.com/IBM/AMLSim/) is a synthetic banking/AML simulator with known laundering patterns and an Apache-2.0 repository license, but its Java/runtime footprint is unnecessary for this offline prototype. [Tide](https://arxiv.org/abs/2603.01863) is a recent open-source synthetic AML generator with structural and temporal patterns, but it was not copied or vendored. PaySim references were reviewed through a public dataset mirror; because the original provenance and distribution terms are not needed for this project, no PaySim files are redistributed. The shipped generator is original, small, seeded, and purpose-built for this demo.
- Optional provider use is operator-configured. Synthetic case context should be treated as test data, and outbound provider requests should be disabled for demonstrations unless the operator has reviewed the endpoint and retention terms.
- The local JSON learning artifact is append-only structured state. It cannot modify agent code, policies, or HOCON automatically.
