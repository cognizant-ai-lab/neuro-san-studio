# Incident Update Template

Use this format for stakeholder updates.

```text
Hi Team,

We are observing <impact summary>.

Initial finding:
<short root cause or suspected cause>

Evidence:
- <log evidence 1>
- <log evidence 2>

Current action:
<what is being checked now>

Next update:
<when or after which validation step>

Regards,
Support Team
```

## Rules

- Keep the update concise.
- Do not include credentials, tokens, payloads, or customer data.
- Mention whether the root cause is confirmed or suspected.
- If restart or configuration change is recommended, mention approval requirement.
